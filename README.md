Saat ini saya telah membuat rangkaian aplikasi desktop berbasis JavaFX untuk menghitung Body Mass Index (BMI) berdasarkan berat dan tinggi badan.

## Fitur Utama
- Menghitung nilai BMI secara presisi.
- Menentukan kategori status berat badan.
- Fitur Reset untuk mengosongkan form input.
- Tampilan antarmuka yang menarik menggunakan stylesheet CSS.

## Persyaratan Sistem
- Java Development Kit (JDK) 11 atau lebih baru.
- Apache NetBeans IDE.
- Scene Builder.

## Cara Menjalankan Proyek
1. Clone atau unduh repositori ini.
2. Buka proyek menggunakan **Apache NetBeans**.
3. Buka package `com.mycompany.kalkulatorbmi` dan cari file `KALKULATORBMI.java`.
4. Klik kanan pada file `KALKULATORBMI.java` -> pilih **Run File** (atau tekan `Shift + F6`).
